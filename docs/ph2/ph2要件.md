# ph2設計

## 概要
現在公開できているだけ、の状態の地震ランキングサイトを収益化する。

## そもそもph1,ph2とは？
そもそもph1というフェーズの区分すら作っていなかった。とりあえず収益化を目指してサイト作成をしてきたが、現状の地震ランキングサイトは公開できる状態にはなっていない。とはいえ本番公開できるレベルにまで到達しているので、現段階までを"ph1"、これから収益化に向けて行う作業を"ph2"と定義する。

## ph2実現したいこと
- AdSense収益化を実現したい
- アフィリエイト収益化はやらない（ph3以降で検討）

## AdSense収益化のために必要なこと検討
ph1でボトルネックになったのがAdSense審査通過である。
- AdSense審査に通過するためには必要なのは？
    - コンテンツの質や量が重要であるため、まずはコンテンツを充実させる必要がある。
- 必要なコンテンツの質とは？
    - 核心
        - 機械生成データを“人間向けに解釈・説明していること”
    - 具体例
        - ①データの意味付け（今週の地震活動は何が言えるか）
        - ②指標の定義と妥当性（なぜこのランキングなのか）
        - ③利用上の注意や限界（予測ではない・観測条件）
    - これらを自サイトの言葉で継続的に説明している状態
- 必要なコンテンツの量とは？
    - 「単一ページ完結ではない」ことが最低ラインで、目安は静的でも3〜5本以上の説明系ページが必要。
    - 各ページが数百文字以上で相互リンクされていれば量としては十分。↓例
        - トップ
        - このサイトについて
        - 集計方法
        - データの見方
        - よくある質問（FAQ）

## サイトコンテンツ要件
docs/デザイン/index.htmlのデザインを参考に要件を整理する。
datadogのダッシュボードを参考にして、発生した地震の情報を表示する

### メインページ
- ヘッダーセクション
    - ロゴ　タイトル　地震ランキング
    - 東証みたいに横に流れる地震情報表示
- newsセクション
    - 手動更新
- サマリーセクション
    - 5~10行程度の文章
        - 発生回数/面積のランキング（回/1000km²で比較 => 回数割る面積掛ける1000）
        - 震度3以上の地震が発生したのは
        - 急上昇都道府県について
        - 直近の地震情報
- 今週の都道府県ごとの地震ランキング（回数/10^4km^2）ヒートマップセクション
- 今週の都道府県ごとの地震ランキング（回数/10^4km^2）上位10都道府県一覧セクション
    - 47都道府県全部の集計結果ページへのリンク
- 24時間の地震発生履歴セクション
    - 地震詳細ページへのリンク
    - 最大5件表示
- 週間推移セクション
    - TVal nowのようなグラフ
- アフィリエイト誘導セクション
    - 防災用品
- カスタムセクション
    - あらかじめ設定しておいたhtml形式の文章を表示できるようにする
- フッターセクション

### 都道府県ごとの集計ページ
- ヘッダー（共通）
- 都道府県サマリー
    - 期間
    - 地震回数
    - 回数 / 10⁴km²
    - 全国順位
    - 震度3以上の有無
- ミニ時系列グラフ（7日 or 30日）
- 最近の地震一覧（その都道府県のみ）
- 全国平均との差分コメント（短文）
- CTA
    - 全国ランキングへ
    - 詳細推移ページへ

### 47都道府県の集計結果ページ
- メインページで10位まで表示しているが、47都道府県全部の集計結果ページも用意する。

### 過去7日間の地震履歴ページ
- メインページで24時間分の地震発生履歴を表示しているが、過去7日間分の地震履歴ページも用意する。

### 地震詳細ページ
- xmlの内容に色付けする程度

### 推移詳細ページ
- ヘッダー（共通）
- 指標切替
    - 回数
    - 回数 / 10⁴km²
    - 震度3以上
- 時系列グラフ
    - 7日 / 30日 / 90日
- 簡潔な解説（2〜3行）
    - 「一時的な増加」「平常レンジ」など断定しない表現
- 都道府県別切替

## 収益化要件
- AdSense審査に通過すること
    - コンテンツの質と量の確保
- 細かいSEOはこだわらない
- アフィリエイトはph3以降で検討

## データ要件
- 最新の地震（過去6時間以内の地震のうち大きい順に10件）
- 本日の大きい地震ランキング（過去24時間で発生したM3.0以上の地震のうち大きい順に10件）
- 今週の大きい地震ランキング（過去168時間で発生したM4.0以上の地震のうち大きい順に10件）
- 今月の大きい地震ランキング（過去720時間で発生したM5.0以上の地震のうち大きい順に10件）
- 本日の都道府県別地震回数ランキング（回/1000km²）（47件）
- 今週の都道府県別地震回数ランキング（回/1000km²）（47件）
- 地震発生頻度急上昇都道府県（10件）
    - score = (24h回数 + 1) / (7日平均 + 1)
    - 条件（AND）:
        - 24h回数 ≥ 3
        - score ≥ 2.0

## 共通言語
### 地震
震源で1回発生した現象。
一般的な地震のイメージのこと。
属性：震源、発生時刻、マグニチュード
UI表記：地震
### 都道府県震度
都道府県ごとの震度単位の地震。
同じ震源地で発生した地震でも、都道府県が異なれば別の都道府県震度とする。
属性：震度、観測時刻、都道府県
UI表現：都道府県ごとの地震
