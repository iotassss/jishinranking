# ■ ① 地震スコア（基本）

```math
[
\boxed{
G(p,t)=\sum_i w(I_i),e^{-\frac{t-t_i}{\tau}}
}
]
```

**日本語置き換え：**

[
\boxed{
地震スコア = \sum (震度の重み \times 時間減衰係数)
}
]

* (G(p,t))：その都道府県の現在の地震スコア
* (w(I_i))：各地震の震度に応じた重み
* (t-t_i)：その地震が何日前か
* (\tau)：どれくらい「最近」を重視するか

---

# ■ ② 震度 → 重み

[
\boxed{
w(I)={1,2,4,8,16,24,40,64,100}
}
]

**日本語置き換え：**

[
\boxed{
震度の重み = 震度が大きいほど急激に増える係数
}
]

---

# ■ ③ 短期スコア

[
\boxed{
G_{\text{short}}=\sum_i w(I_i),e^{-\frac{t-t_i}{\tau_s}}
}
]

**日本語置き換え：**

[
\boxed{
短期スコア = 最近の地震を強く評価した合計スコア
}
]

* (\tau_s)：短期（例：7〜14日）

---

# ■ ④ 長期スコア

[
\boxed{
G_{\text{long}}=\sum_i w(I_i),e^{-\frac{t-t_i}{\tau_l}}
}
]

**日本語置き換え：**

[
\boxed{
長期スコア = 普段の地震活動レベルを表すスコア
}
]

* (\tau_l)：長期（例：60〜90日）

---

# ■ ⑤ 急上昇度（最重要）

[
\boxed{
R=\frac{G_{\text{short}}}{G_{\text{long}}+\epsilon}
}
]

**日本語置き換え：**

[
\boxed{
急上昇度 = 最近の地震量 ÷ 普段の地震量
}
]

* (R)：どれくらい増えているか（倍率）
* (\epsilon)：ゼロ割防止の小さな値

---

# ■ ⑥ 判定条件（実用）

[
\boxed{
R > R_{\text{th}} ;\land; G_{\text{short}} > G_{\min}
}
]

**日本語置き換え：**

[
\boxed{
急上昇度が閾値を超え かつ 最近の地震量が一定以上
}
]

* (R_{\text{th}})：急上昇とみなす倍率
* (G_{\min})：ノイズ除去のための最低スコア

---

# ■ 超要約（1行）

[
\boxed{
地震スコア = 「震度の強さ × 最近さ」を全部足したもの
}
]

[
\boxed{
急上昇度 = 最近 ÷ 普段
}
]

# ■ 実装例（Go）
```go
package main

import (
	"fmt"
	"math"
	"time"
)

type Earthquake struct {
	Time      time.Time // 発生時刻
	Intensity float64   // 震度（例: 1,2,3,4,5.0,5.5,6.0,6.5,7）
}

// 震度 → 重み
func weight(intensity float64) float64 {
	switch {
	case intensity < 1.5:
		return 1
	case intensity < 2.5:
		return 2
	case intensity < 3.5:
		return 4
	case intensity < 4.5:
		return 8
	case intensity < 5.0:
		return 16 // 5弱
	case intensity < 5.5:
		return 24 // 5強
	case intensity < 6.0:
		return 40 // 6弱
	case intensity < 6.5:
		return 64 // 6強
	default:
		return 100 // 7
	}
}

// 地震スコア計算（時間減衰付き）
func calcScore(events []Earthquake, now time.Time, tauDays float64) float64 {
	var score float64

	for _, e := range events {
		days := now.Sub(e.Time).Hours() / 24.0
		if days < 0 {
			continue
		}

		decay := math.Exp(-days / tauDays)
		score += weight(e.Intensity) * decay
	}

	return score
}

type SpikeResult struct {
	ShortScore float64
	LongScore  float64
	Ratio      float64
	IsSpike    bool
	AlertScore float64
}

// 急上昇判定
func CalcSpike(events []Earthquake, now time.Time) SpikeResult {
	// パラメータ（調整可能）
	tauShort := 14.0 // 日（短期）
	tauLong := 90.0  // 日（長期）
	epsilon := 5.0   // ゼロ割防止
	rThreshold := 2.0
	gMin := 20.0

	short := calcScore(events, now, tauShort)
	long := calcScore(events, now, tauLong)

	ratio := short / (long + epsilon)

	isSpike := ratio > rThreshold && short > gMin

	// 強さ × 急上昇
	alertScore := short * math.Log1p(ratio)

	return SpikeResult{
		ShortScore: short,
		LongScore:  long,
		Ratio:      ratio,
		IsSpike:    isSpike,
		AlertScore: alertScore,
	}
}

func main() {
	now := time.Now()

	// サンプルデータ
	events := []Earthquake{
		{Time: now.Add(-1 * 24 * time.Hour), Intensity: 4},
		{Time: now.Add(-2 * 24 * time.Hour), Intensity: 5.0},
		{Time: now.Add(-3 * 24 * time.Hour), Intensity: 3},
		{Time: now.Add(-10 * 24 * time.Hour), Intensity: 2},
		{Time: now.Add(-40 * 24 * time.Hour), Intensity: 4},
	}

	result := CalcSpike(events, now)

	fmt.Println("短期スコア:", result.ShortScore)
	fmt.Println("長期スコア:", result.LongScore)
	fmt.Println("急上昇倍率:", result.Ratio)
	fmt.Println("急上昇判定:", result.IsSpike)
	fmt.Println("警戒スコア:", result.AlertScore)
}
```
